1. Beschreibung

Dieser Baustein ermöglicht die Steuerung mit einem MPD-Server.

2. Eingänge

Nr. Name Init Beschreibung
1 E1 Hostname "mpd.lan"
Hostname des MPD-Servers.
2 E2 Port 6600
Portnummber des MPD-Servers.
3 E3 Password ""
Passwort des MPD-Servers.
4 E4 Start/Stop 0
Sende 1 für Start und 0 für Stop. Initialwert wird nicht genutzt.
5 E5 Pause/Play 0
Sende 1 für Pause und 0 für Weiter. Initialwert wird nicht genutzt.
6 E6 Volume 0
Lautstärke (0-100). Initialwert wird nicht genutzt.
7 E7 Playlist ""
Name einer Playliste, die ausgewählt werden soll. Initialwert wird nicht genutzt.
8 E8 Next/Prev 0
Sende 1 für nächstes Stück und 0 für vorheriges. Initialwert wird nicht genutzt.
9 E9 Mute 0
Sende 1 für Mute und 0, um die vorherige Lautstärke wiederherzustellen. Initialwert wird nicht genutzt.
10 E10 Mute 0
Repeat-All-Option. Initialwert wird nicht genutzt.
11 E11 Mute 0
Random-Option. Initialwert wird nicht genutzt.

3. Ausgänge

Nr. Name Init SBC Beschreibung
1 A1 Connected 0 sbc
Zeigt den Verbindungsstatus an (1 verbunden, 0 getrennt).
2 A2 Playing 0 sbc
Zeigt an, ob gerade abgespielt wird (1).
3 A3 Volume 0 sbc
Gibt die aktuelle Lautstärke zurück (0-100).
4 A4 Titel "" s
Gibt den aktuellen Titel zurück.
5 A5 Künstler "" s
Gibt den aktuellen Künstler zurück.
6 A6 Album "" s
Gibt das aktuelle Albun zurück.
s = send, sbc = send by change
